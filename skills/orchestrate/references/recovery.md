# Recovery

Use this reference when a task fails, becomes unavailable, or conflicts with branch or pull-request continuity.

Reconcile native task control with remote branch and pull-request progress first. Elapsed time is not failure evidence.

Resume the same task, checkpoint, branch, and pull request when native control permits it. If the original task cannot resume, request one replacement bound to those same artifacts. Apply the charter's attempt limit; after it is exhausted, record `waiting` with the exact blocker and human action.

Multiple implementation branches or pull requests for one ticket are an authority conflict. Preserve the checkpoint's recorded continuity and pause for resolution rather than choosing silently.
