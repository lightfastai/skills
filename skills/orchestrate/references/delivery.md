# Delivery closure

Read this reference when the selected charter coordinates code or document delivery through a pull request.

A child handoff supplies implementation evidence, not merge authority. A completed child review closes exploratory review when it covers the charter's required axes at the handed-off head. The root verifies review scope and head, acceptance, required checks, mergeability, and gates. Repeat exploratory review only when policy requires it or concrete evidence conflicts.

A blocking finding must satisfy the charter's materiality and supported-boundary definition. Apply its repair-round limit; observations outside that bound become follow-up proposals.

When every merge gate passes, request the first permitted merge method at the reviewed head. Independently verify the merged commit on main, record verification and acceptance evidence, close the work unit, and release its isolated workspace only when remote continuity is proven.

Completion requires the matching commit verified on main, complete acceptance evidence, a closed tracker unit, and safe workspace release or the missing proof named.
